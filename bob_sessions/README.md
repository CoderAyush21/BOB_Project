# IBM Bob session reports (required by the hackathon)

After each prompt of the hackathon run (`bob-prompts/hackathon/`), save here:
- the **task session summary screenshot**: `prompt-N-summary.png`
- the **exported session report**, if Bob offers an export: `prompt-N-report.md` (or whatever format Bob exports)

Every team member adds their own. Bob's own progress screenshots go to `screenshots/auto/`.
Never put credentials in here: session reports can contain whatever was typed into the chat.
