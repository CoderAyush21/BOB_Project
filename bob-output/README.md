# bob-output/

These files were produced by IBM Bob 2.0 during the Bug Vaccine hackathon run (27 September 2026). Every file was generated or verified by Bob across 7 prompts in Agent mode; no file was hand-written. The deterministic scripts (`vaccine/run.py`, `bugvaccine.py`) did the measuring; Bob did the understanding.

| File | What it is |
|---|---|
| `antigens-raw.md` | Raw mined dossier from `vaccine/mine.py` — git diff excerpts and postmortem content fed to Bob in Prompt 2 |
| `antigens.json` | **3 antigens** (A41, A57, A63) extracted by Bob: pattern, regex signatures, fix recipes, example before/after, and sample antibody per bug |
| `knowledge.json` | Compiled knowledge base from `bugvaccine.py learn`; fed to the debugger, patch, guard and rules commands |
| `mutants.json` | **6 mutants** (M1–M6) found by 3 parallel subagents in Prompt 3: one per antigen × 2 re-entry sites each |
| `mutants.holdout.json` | **6 held-out mutants** (H1–H6) designed by fresh independent subagents in Prompt 5 — novel attack strategies never shown to the antibody writer |
| `mutants.pr.json` | **2 PR mutants** (P1–P2) targeting the safe new code in `refunds.js`; used by `bugvaccine.py pr` in Prompt 6 |
| `results-before.json` | Runner output **before** antibodies: 2/6 (33%) immunity |
| `results-after.json` | Runner output **after** antibodies: 6/6 (100%) immunity |
| `results-holdout.json` | Runner output on held-out mutants: 6/6 (100%) held-out immunity |
| `results-pr.json` | PR mode result for PR #88 before patch: 3 new-code matches, 0/2 mutant immunity |
| `results-pr-after.json` | PR mode result after `patch --apply`: 0 new-code matches, 0/2 mutant immunity (refunds tests still incomplete) |
| `antibodies.test.js` | **23 antibody tests** written by Bob in Prompt 4; guards each bug pattern at every affected function |
| `report.html` | HTML report (before/after) from Prompt 4 |
| `report-before.html` | HTML report — baseline (33%) |
| `report-holdout.html` | HTML report — held-out mutants (100%) |
| `pr-comment.md` | GitHub-style PR comment generated by `bugvaccine.py pr`; reports new-code risks and untested regression sites |
| `patch-report.json` | Output of `bugvaccine.py patch --apply`: 3 fixes applied, 0 lines needing human, tests pass, re-scan clean |
| `cure.json` | Dashboard data combining patch, PR-after, guard and rules results |
| `bug-vaccine.semgrep.yml` | **3 Semgrep rules** exported by `bugvaccine.py rules` — one per antigen, ready for IDE and CI integration |
| `rag-index.json` | RAG index built by `bugvaccine.py index`; 11 chunks (3 fix, 3 pattern, 5 postmortem) |
| `dashboard.html` | Full interactive dashboard (offline, single file) for the complete run |
| `logs/prompt-1.md` | Session log — Prompt 1: setup, merge, secret scan |
| `logs/prompt-2.md` | Session log — Prompt 2: document understanding, antigen extraction |
| `logs/prompt-3.md` | Session log — Prompt 3: parallel subagent hunt |
| `logs/prompt-4.md` | Session log — Prompt 4: antibody writing, 33% → 100% |
| `logs/prompt-5.md` | Session log — Prompt 5: blind held-out check (+ honesty correction added in Prompt 6) |
| `logs/prompt-6.md` | Session log — Prompt 6: PR review, cure and prevent |
| `logs/prompt-7.md` | Session log — Prompt 7: verification, dashboard, write-up |
