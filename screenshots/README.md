# Screenshots (required hackathon deliverable)

| Folder | Who makes it | What |
|---|---|---|
| `../bob_sessions/` | **You**, after each prompt | IBM Bob **task session summaries and exported reports**. The hackathon template requires this folder, from **every team member**. |
| `auto/` | **Bob**, via `tools/screenshot.ps1` | Progress evidence: Bob working, subagents running, and the reports rendered to images |

Bob can't capture its own session summary, because the summary only appears after Bob's task has ended. That's why you save those yourself, in `bob_sessions/`.

Before any screen capture, close private windows (email, chats, password managers).
