# Screenshots (required hackathon deliverable)

| Folder | Who makes it | What |
|---|---|---|
| `manual/` | **You**, at each ⏸ stop in the master prompt | IBM Bob **task session summary**, e.g. `phase-3-summary.png`. The hackathon requires these, from **every team member**. |
| `auto/` | **Bob**, via `tools/screenshot.ps1` | Progress evidence: Bob working, subagents running, and the reports rendered to images |

Bob can't capture its own session summary, because the summary only appears after Bob's task has ended. That's why `manual/` exists.

Before any screen capture, close private windows (email, chats, password managers).
